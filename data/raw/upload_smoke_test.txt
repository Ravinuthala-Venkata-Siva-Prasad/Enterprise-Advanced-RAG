Document ID: RAG-UPLOAD-TEST-001

Project: Enterprise Advanced RAG

The document upload smoke test uses FAISS for dense vector search and BM25 for sparse keyword retrieval.

The system supports incremental document indexing. When a new document is uploaded, its chunks are embedded and added to both FAISS and BM25 without rebuilding the existing index.

The embedding model used in this project is sentence-transformers/all-MiniLM-L6-v2 with a vector dimension of 384.

The document management service supports PDF, DOCX, TXT, CSV, and HTML files.
